# Incredible India · Dark Atlas

An interactive dark-themed 3D map of India with 90+ travel places.

- Real state, district and river boundaries
- Click a pin for details, best months, distances, nearby places
- Filters, trip planner, saved places, tour mode

Open `index.html` in any browser. No build step needed.

Live demo (GitHub Pages): enable it under Settings → Pages → Deploy from branch → main.
